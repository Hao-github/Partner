# 演进与验收

状态基线：2026-11-06。已有文本聊天 MVP，M3 的 MCP 工具部分已实现；阶段不代表已发布版本，也没有承诺完成日期。

## 当前验收

已覆盖 CLI / QQ 私聊、历史与会话隔离、模型切换、工具循环、供应商请求与重试、回复缓存重推、事务回滚、跨渠道版本命令和 MCP 关闭流程。最近一次验证为 8 个测试模块、93 项测试（2026-11-06，移除已退役时钟的专用测试，保留旧工具拒绝验证）；第三种 Provider / Channel 使用测试替身验证工厂扩展，不代表已接入真实新平台。

QQ 本人私聊此前做过真实收发与时间工具联调，高德官方 MCP 北京天气也已验证；本轮退役本地时间工具，未重复外部联调。本地测试不代替新部署的消息权限或持续运行验证。

## 阶段安排

| 阶段 | 目标 | 架构改动范围 | 完成条件 |
| --- | --- | --- | --- |
| M1 待实现 | 输入预算及可靠运行 | core 上下文、渠道关闭/交付、storage 迁移、部署配置 | 长输入有明确行为；SIGTERM 可控退出；发送失败按策略恢复或明确终止；备份可恢复 |
| M2 待实现 | 稳定人设与最小长期记忆 | core 上下文/记忆、models 结果契约、storage 记忆与事务 | 人设可配置；记住/查看/修改/忘记可验证；重启及跨用户隔离正确 |
| M3 部分完成 | 完成一个有价值的外部任务 | MCP 版本及高德天气已实现；运行时 Skill 待实现 | 真实任务端到端可用；失败、资源关闭和能力边界有测试；Skill 需另行验收 |
| M4 待实现 | 有预算的后台记忆整理 | core 维护用例、storage 游标/版本 | 重跑幂等、重启可续、冲突与忘记有效、不阻塞前台 |
| M5 待决策 | 主动提醒或更多平台 | 持久任务、投递契约及具体渠道/供应商实现 | 先明确平台权限、身份、时区和触发语义，再实现所选场景 |

M1 的运行改进与 M2 的静态人设可以分别迭代。长期记忆先于睡梦整理；有实际工具能力后再做依赖这些工具的 Skill。MCP 和 Skill 不要求同时实现，也不作为 MVP 完成的前置条件。

M3 的 Skill 指管家运行时能力，尚待实现；仓库内 Codex 开发技能用于维护流程，可独立使用。开发技能见 [OPT-015](../archive/CHANGELOG.md#opt-015)，MCP 实现见 [OPT-016](../archive/CHANGELOG.md#opt-016)。当前优化选择见 [评审摘要](optimizations/review.md)。

## 架构完整性清单

| 维度 | 当前边界 | 需要补齐或保留的约束 |
| --- | --- | --- |
| 模块依赖 | 主流程不维护平台名单，具体平台不访问存储 | 新能力有明确归属，避免反向导入和跨层共享连接 |
| 数据协议 | 文本/工具消息、不可变请求与结果数据类 | 新媒体或认证方式超出契约时显式扩展，不伪装成零改动接入 |
| 上下文 | 最近完整轮次、输出与工具轮数限制 | 输入、工具结果和整轮预算，必要时摘要 |
| 持久化 | 轮次、会话模型和缓存事务一致 | schema 迁移、恢复验证；新记忆与确认结果原子提交 |
| 交付 | 平台重推复用缓存 | 主动补发所需路由、有效期限、所有权、幂等和永久失败状态 |
| 生命周期 | finally 关闭、停止事件、有界 QQ 队列、MCP 会话/进程释放 | SIGTERM、整轮截止、关闭超时 |
| 身份和权限 | 渠道白名单、会话命名空间、只读版本/天气工具 | 长期记忆拥有者、显式跨渠道绑定、有副作用工具授权与执行记录 |
| 后台维护 | 尚未实现 | 持久游标、版本冲突、忘记标记、取消及预算 |
| 运维 | 本地运行、安全日志、Conda 环境 | 单实例常驻、依赖可复现、健康状态、备份和发布回退 |
| 验证 | 最近 93 项本地测试、Ruff、Pyright 通过 | 每项新能力有行为验收，真实环境与故障验证分别记录 |

## 验证落点

| 测试模块 | 现有职责 | 后续适合加入 |
| --- | --- | --- |
| test_app.py | 组装、入口、模型切换和扩展流程 | 人设/记忆/工具的整条用户流程 |
| test_channels.py | 公共历史、缓存与 CLI | 新结果契约、忙碌和发送恢复行为 |
| test_config.py | 环境快照、配置边界、凭据隐藏 | 新资源路径和启动配置 |
| test_core.py | 模型/工具循环、本地工具 | 上下文预算、技能选择、记忆策略和维护冲突 |
| test_mcp.py | stdio 发现/调用、版本上下文、天气允许列表、失败和关闭 | 新传输、权限、结果预算及重连策略 |
| test_providers.py | 协议转换、请求和重试 | 新供应商消息、工具及错误格式 |
| test_qq.py | QQ 启动、渠道、HTTP、网关 | 停止信号关联行为、补发、平台有效期限 |

复用对应 TestCase 与 helpers；只在出现独立职责或规模确实过大时拆模块。模型替身只存在于测试，使用临时库；真实服务联调单独执行，不让单元测试消费账户额度或访问私人数据。

## 尚待具体场景决定

- 下一项外部任务与运行时 Skill 场景；首项已选择并接入高德天气。
- 新供应商、渠道、媒体类型与跨渠道身份绑定，不为名单中的每种服务预建空实现。
